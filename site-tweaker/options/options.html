JavaScript 正以兼容模式运行。 对 GitHub 这类有严格安全策略（CSP）的网站，脚本可能被拦截；CSS 不受影响。

    每行一个，以 ! 开头表示排除
    写法说明与网址测试
    github.com该域名及其所有子域名（如 gist.github.com），任意页面
    www.zhihu.com/question该域名下，路径以 /question 开头的页面
    localhost:3000本机指定端口
    https://*.example.com/news/*Chrome 标准匹配模式，按原样精确匹配
    !gist.github.com排除这些网址（优先于其他行）
    *所有网站
    # 备注以 # 开头的行会被忽略
    保存后已打开的页面立即生效；被原样式覆盖时可加 !important 保存后刷新页面生效；可直接使用 await
